Manage Projects

Feeds the Project dropdown on Upload and the document filters. Each project automatically gets a folder in Files, and each sub-item gets a subfolder inside it. Click an entry to expand and add sub-items (e.g. towers/blocks) under it. Entries in use by an existing document can't be edited or deleted.

Manage Departments

Feeds the Department dropdown on Upload, Create User, and the Documents filter. Entries in use can't be edited or deleted.

Manage Document Categories

Feeds the Document Category dropdown on Upload and the Documents filter. Click an entry to expand and add sub-items (e.g. document types) under it. Entries in use can't be edited or deleted.

Manage Roles

Feeds the Role dropdown on Create User and Workflow Configuration. Renaming a role is always safe (accounts reference the role by ID, not name) — but a role assigned to an existing user or workflow step can't be deleted. Admin is a built-in role and can't be edited or removed.

Workflow Configuration

Configure the document approval workflows. Changes only apply to documents uploaded after saving.
One workflow per Document Category — click a category to configure it directly. No manual ordering needed: add mappings with a Role, a From Status, and a To Status, and the sequence is worked out by matching each step’s To Status to the next step’s From Status. Steps sharing a From Status run in parallel.

Status Labels

The 5 built-in statuses drive the real document lifecycle — you can rename their display text but not remove them. Custom statuses are additional reference values usable in Workflow Configuration's From/To Status mappings.

User Access

Select a user to configure their roles, project assignments, and page access in one place. Admin always has full access and is not listed here.
